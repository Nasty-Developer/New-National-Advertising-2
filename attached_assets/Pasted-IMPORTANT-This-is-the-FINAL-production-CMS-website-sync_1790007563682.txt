==================================================
1. ADMIN PANEL = REAL WEBSITE CMS
==================================================

The Admin Panel must not be a separate demo/editor.

It must be the actual CMS for the live website.

The complete flow must be:

Admin Panel
↓
Backend API
↓
Firebase / Firestore
↓
Persistent data
↓
Public API
↓
Public Website

If I edit something in Admin Panel and save it successfully, the public website must use the new value.

After refreshing the public website, the new value must still be there.

NO hardcoded data should override CMS-managed data.

==================================================

==================================================

- Change service order
- Publish/unpublish service
- Archive/remove service
- Add/edit/remove products belonging to that service

Changes must appear on the public website.

- Change order/position

"Premium Star Flex"

16. ERROR HANDLING
==================================================

Never show "Saved successfully" unless the backend actually confirms success.

For every mutation:

Loading
↓
API request
↓
Backend validation
↓
Database update
↓
Success response
↓
Refresh UI

If anything fails:

- show error
- preserve existing data
- do not clear the form
- do not show fake success
- do not partially corrupt the record

Handle:

- 400 errors
- 401 errors
- 403 errors
- 404 errors
- 500 errors
- Firebase errors
- Storage errors
- network failures
- invalid data
- duplicate submissions
