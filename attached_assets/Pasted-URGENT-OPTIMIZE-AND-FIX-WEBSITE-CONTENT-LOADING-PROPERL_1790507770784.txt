2. OPTIMIZE API CONTENT LOADING
========================================

Inspect all API requests.

Find:

- duplicate API requests
- unnecessary requests

Products
Services
Categories
Machines
Website content

========================================
3. PREVENT CONTENT FROM DISAPPEARING
========================================

This is extremely important.

If content has already successfully loaded:

DO NOT replace it with an empty array/null while another request is running.

Never do:

loaded data
→ loading
→ []
→ blank section
→ data again

Instead:

loading
→ current data
→ keep current data visible while refreshing

If an API request fails temporarily, preserve the last valid content.

========================================
4. FIREBASE OPTIMIZATION
========================================

Inspect Firebase/Firestore queries.

Make sure:

- unnecessary reads are removed
- the same collection isn't fetched repeatedly
- queries are properly scoped
- only required fields/data are loaded where possible
- listeners are cleaned up
- duplicate listeners are not created
- components don't create new subscriptions on every render

If real-time listeners are not required for a section, do not use an unnecessary real-time listener.
